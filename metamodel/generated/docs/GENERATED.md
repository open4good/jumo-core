# Generated documentation site

Every page under this directory is generated by `scripts/generate/generate-metamodel.sh` from
`metamodel/jumo-v1.yaml`. Do not hand-edit; edit the LinkML source and regenerate. (One banner
file at the site root, not one per page: gen-doc's Jinja templates have no per-page header/footer
hook without a custom `--template-directory`, and mutating 900+ generated Markdown files
line-by-line every run was judged not worth it for a machine-obvious fact -- every file in this
directory is produced by the same command.)
