# Class: ThemePack


_Naming, voice and visual presentation. Decorative and linguistic only: a theme carries no capability, policy, budget, assurance or workflow field, so renaming an agent cannot change what it may do. Open string-keyed maps in the source schema (terminology, roleOverrides, objectForms, rooms) are modeled as lists of key/value entries -- LinkML has no direct patternProperties/additionalProperties-map equivalent; the list form is exact for reading and writing, and Rego can still check "no duplicate key" as an invariant._
