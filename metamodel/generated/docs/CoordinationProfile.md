# Class: CoordinationProfile


_A named, reusable coordination profile: authorized mechanisms, target dependencies, rhythm, and preconditions for team coordination. Distinct from TeamSpec.coordination (inline, per-team) -- a CoordinationProfile is declared once and referenced by name from multiple teams or improvement-loop targets, while TeamSpec.coordination is that team's own binding. Already used mechanisms[] in the source schema (unlike TeamSpec's single `mode`), so this class's mechanisms list was not itself the redesign target -- it gains the same CoordinationMechanismBinding shape as TeamSpec for vocabulary consistency, replacing what was a flat CoordinationMechanism list._
