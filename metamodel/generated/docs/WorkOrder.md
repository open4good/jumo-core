# Class: WorkOrder


_One unit of dispatched work, in Git. Renamed from WorkItem. Carries debtor, creditor, and condition (docs/concepts/positionnement-conceptuel.md#engagements-sociaux): an accepted order is not yet a social commitment without a named debtor, creditor, and discharge condition. The existing state enum (PROPOSED..FAILED) is retained as the closest Git-contract analogue of create/accept/discharge; the fuller create/discharge/release/cancel/assign operation set belongs to the runtime Matter/Episode this Git file is not -- this module models Git contracts only._
