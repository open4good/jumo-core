# Class: ConnectorPackageCertification


_Platform-only technical certification of an exact ConnectorPackage build. Records CI-verified digests only (ADR-0050 decision 8); carries no Realm consent, activation or secret-authority field. Distinct from the Realm-scoped ConnectorAppraisal, which records human dual-consent appraisal._
